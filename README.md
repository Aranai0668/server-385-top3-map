# Last Asylum — Server 385 Top 3 Map

Private/separate planning map for the Server 385 Top 3.

This deployment uses the same Supabase project as the main Server 385 map, but a different map ID:

`server-385-top3`

That keeps alliances, territory assignments, and markers separate from the public Server 385 map.

The frontend expects an Edge Function named:

`last-asylum-map-top3`
